See [Google's AI content requirements](https://support.google.com/merchants/answer/14743464?hl=en-GB).

The feed trial uses existing verified single sizes, existing GBP prices and archival-paper information already in the shop's help/quality content. Size enrichment is omitted if a trial product later has multiple sizes, until variant-specific offers are implemented. Measure Merchant Center free-listing impressions and clicks at two and four weeks after deployment, alongside unchanged products; eight image changes and five copy changes overlap, so this is a practical trial rather than an isolated causal test.
